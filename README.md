# 海南省信用风险预测系统

基于Vue 3 + Element Plus开发的智能信用风险预测平台，为个人、企业、政府和科研机构提供全方位的信用风险评估与监控服务。

## 🌟 系统特色

- **多角色支持**：支持个人、企业、政府、科研四种用户角色
- **AI驱动**：基于人工智能算法的智能信用评估
- **实时监控**：企业信用风险实时监控与预警
- **数据可视化**：直观的数据展示和风险分析
- **响应式设计**：适配各种设备的现代化界面

## 🎯 用户功能模块

### 👥 个人用户
- **个人信用评估**：基于个人信息的信用风险评估
- **风险预测**：AI算法驱动的信用风险预测
- **历史记录查询**：风险评估历史记录管理

### 🏢 企业用户
- **企业信用中心**：企业基本信息管理与展示
- **风险预测**：企业信用风险评估
- **财务分析**：财务报表智能分析
- **风险监控**：实时风险监控与预警
- **信用报告**：企业信用报告生成

### 🏛️ 政府用户
- **风险监控**：企业风险实时监控系统
- **行业分析**：行业风险分析与统计
- **监管报告**：监管数据报告生成
- **定向推送**：优质企业推荐推送

### 🔬 科研院所
- **算法研发**：信用风险算法开发与测试
- **性能监控**：算法运行性能监控
- **测试验证**：算法效果测试与验证

## 🛠️ 技术架构

### 前端技术栈
- **框架**：Vue 3 + Composition API
- **路由**：Vue Router 4
- **UI组件**：Element Plus
- **构建工具**：Vite
- **开发语言**：JavaScript

### 项目结构
```
src/
├── views/                 # 页面视图组件
│   ├── Home.vue          # 首页
│   ├── Login.vue         # 登录页面
│   ├── Dashboard.vue     # 主仪表板
│   ├── personal/         # 个人用户模块
│   ├── enterprise/       # 企业用户模块
│   ├── government/       # 政府用户模块
│   └── research/         # 科研院所模块
├── router/               # 路由配置
│   └── index.js         # 路由定义
├── App.vue              # 根组件
└── main.js              # 应用入口
```

## 🔧 开发指南

### 路由配置
系统采用嵌套路由设计，Dashboard作为父路由，各用户模块作为子路由：

```javascript
{
  path: '/dashboard',
  component: Dashboard,
  children: [
    { path: 'enterprise', component: EnterpriseDashboard },
    { path: 'government', component: GovernmentDashboard }
  ]
}
```

### 用户认证
- 基于本地存储的用户类型识别
- 登录后自动跳转到对应角色仪表板
- 路由守卫确保访问权限

### 组件设计
- 采用Vue 3 Composition API
- 模块化组件设计
- 响应式数据绑定
- 统一的UI风格
└── main.js              # 入口文件
```

## 使用说明

1. **登录系统**：访问系统后选择用户类型（个人/企业/政府/科研）进行登录
2. **功能导航**：登录后通过左侧菜单导航到不同功能模块
3. **数据输入**：在风险预测页面输入相关数据
4. **结果查看**：系统会自动计算并展示风险评估结果
5. **历史查询**：可以查看历史评估记录和详情

## 开发说明

### 组件设计原则
- 模块化设计，便于维护和扩展
- 响应式布局，支持不同屏幕尺寸

- 使用Vue 3 Composition API进行状态管理

- 预留接口便于后端数据对接
- 组件设计支持功能扩展
- 路由配置支持新模块添加
